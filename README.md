# Emmanuel Kyei — Personal Website V1

Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub Pages repository.

For a user site, GitHub's documented format is `<username>.github.io`. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.

Before publishing:
1. Replace `YOUR-EMAIL@example.com`.
2. Replace the three `#` social links.
3. Replace the artwork placeholders with your actual images/content.

V1 is intentionally a clean static site so it can run directly on GitHub Pages.
